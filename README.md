# Kensho Apps

日本市場データの Apify Actor と MCP Server のカタログ。

## 製品
- Apify Store: fruitful_quintessence — 日本の EC サイト・不動産・ゴルフ・イベントのスクレイピング Actor
- Gumroad: atushi5.gumroad.com/l/kutuxe — スクレイピング結果のデータセット

## 関連リポジトリ
- japan-geospatial-open-data-mcp — GSI・e-Stat・国土数値情報の MCP Server
- golfpartner-used-club-scraper — ゴルフパートナーの中古クラブ在庫スクレイパー

## 使い方
Apify Actor は apify.com から、MCP Server は対象リポジトリからインストールする。
データセットは Gumroad で配布する。
